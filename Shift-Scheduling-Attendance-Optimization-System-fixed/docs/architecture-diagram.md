## Scheduling Algorithm Flow

```
┌─────────────────┐
│  Input: Shifts,  │
│  Employees,      │
│  Constraints     │
└────────┬─────────┘
         ▼
┌─────────────────┐
│ Sort shifts by   │
│ date, then time  │
└────────┬─────────┘
         ▼
┌─────────────────┐     ┌─────────────────┐
│ For each shift:  │────▶│ Get candidates:  │
│                  │     │ all active       │
└────────┬─────────┘     │ employees        │
         │               └────────┬─────────┘
         │                        ▼
         │               ┌─────────────────┐
         │               │ Apply Hard       │
         │               │ Constraints:     │
         │               │ • Leave check    │
         │               │ • Availability   │
         │               │ • Overlap check  │
         │               │ • Skills match   │
         │               │ • Max hours/week │
         │               │ • Min rest hours │
         │               │ • Max shifts/week│
         │               │ • Max staffing   │
         │               └────────┬─────────┘
         │                        ▼
         │               ┌─────────────────┐
         │               │ Score remaining  │
         │               │ Soft Constraints:│
         │               │ • Fairness       │
         │               │ • Preference     │
         │               │ • Night rotation │
         │               └────────┬─────────┘
         │                        ▼
         │               ┌─────────────────┐
         │               │ Sort by score    │
         │               │ DESC, empId ASC  │
         │               │ (deterministic)  │
         │               └────────┬─────────┘
         │                        ▼
         │               ┌─────────────────┐
         ◀───────────────│ Assign top N     │
                         │ employees        │
                         └─────────────────┘
```
